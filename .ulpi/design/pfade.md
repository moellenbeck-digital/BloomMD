# Abschnitt Pfade `landing-paths` (bindet an `DESIGN.md`)

| Punkt | Regel |
|---|---|
| Nutzer will | den passenden Einstieg wählen: lokal, Web/Team oder Roadmap |
| Layout-Familie | Weggabel aus einem Punkt. Ab 768 px drei gebogene Äste (16 → 0,6) mit versetzten Höhen: erster Weg unten, letzter oben, Spalten stufen mit. Darunter Stamm links mit gebogenen Ansätzen |
| Verboten hier | Karten, Icon-Kacheln, Schatten, Hover-Anheben. Die Zier-Icons entfallen, der Ansatz ersetzt sie |
| Titel | `h2` je Weg, Alegreya 1,75 rem. Der erste Weg trägt den Akzent im Ansatz (Primärweg) |
| Link | der ganze Weg ist ein Link (wie bisher). Aktionswort in `bloom-hi` auf kurzem Trieb |
| Hover/Fokus | nur Farbe, 150 ms; Fokusring 2 px `bloom-hi` |
| Motion | beim ersten Sichtkontakt: Trieb wächst Abschnitt für Abschnitt (nur `transform`), Inhalt folgt. Reduced motion: Endbild |
| Texte | unverändert |
