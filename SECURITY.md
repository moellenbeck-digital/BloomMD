# Sicherheitsmeldungen / Security reports

## Deutsch

Bitte melde vermutete Sicherheitslücken vertraulich an **security@bloommd.io**.
Sobald GitHubs private Sicherheitsmeldungen für dieses Repository aktiviert sind,
kannst du alternativ **Security → Report a vulnerability** verwenden. Erstelle
für eine noch nicht behobene Schwachstelle kein öffentliches Issue.

Nenne die betroffene BloomMD-Version und Plattform, die Auswirkung und Schritte
zur Reproduktion mit Testdaten. Sende keine echten Vault-Inhalte, Zugangsdaten,
Dateinamen oder personenbezogenen Daten. Wir bestätigen den Eingang und stimmen
weitere Details und eine mögliche Offenlegung über den vertraulichen Kanal ab.

Diese Richtlinie gilt für die Anwendungen, Dienste und Plugins, deren Quellcode
in diesem Repository gepflegt wird. Die jeweils veröffentlichten Versionen und
Plattformen stehen auf [bloommd.io/download](https://bloommd.io/download).

## English

Please report suspected vulnerabilities privately to **security@bloommd.io**.
Once GitHub private vulnerability reporting is enabled for this repository, you
may instead use **Security → Report a vulnerability**. Do not open a public issue
for an unpatched vulnerability.

Include the affected BloomMD version and platform, impact, and reproduction
steps using synthetic data. Do not send real vault content, credentials, file
names, or personal data. We will acknowledge the report and coordinate details
and any disclosure through the private channel.

This policy covers the applications, services, and plugins maintained in this
repository. Published versions and platforms are listed at
[bloommd.io/download](https://bloommd.io/download?lang=en).
