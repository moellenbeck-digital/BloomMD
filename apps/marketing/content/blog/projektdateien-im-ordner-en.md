# Create a new project file in the right folder

When project knowledge spans several Markdown files, choosing the destination folder is part of creating a new note. In BloomMD Desktop 0.6.0 you can start in the folder overview.

Select a folder such as **Team**, then **New file**. The dialog uses Team as the destination. Enter a filename and optionally choose a template. BloomMD opens the new file as an editable map. An existing file is not overwritten.

![Native macOS folder overview with the Team folder and its Projektplan file](/releases/desktop-0.6.0-overview.png)

Inside a file, nodes are its Markdown headings. **Tab** adds a child node; its title input receives focus once the node is visible. **Enter** accepts the title and **Escape** cancels the title change. Open the node editor to write the accompanying text.

![The Ziele section selected with its text editor open in the native macOS app](/releases/desktop-0.6.0-editor.png)

**Back to folder overview** saves changes and returns to the files. This lets you move between project plans, ideas and decisions while keeping folders distinct from content nodes.

The screenshots show the native macOS test build with sample data. These changes belong to [Desktop 0.6.0](https://github.com/moellenbeck-digital/BloomMD/releases/tag/v0.6.0); they are not a new Mobile or Obsidian release. See the [desktop guide](/en/docs/desktop) for more steps.
