# Tools and views are grouped more clearly

BloomMD's toolbar has been reorganized so related actions are easier to find. Document, file, search, help and workspace actions now have clearer groups.

The structure is shared by web and macOS. Duplicate or overloaded icons were reduced while translations and keyboard paths remain part of the same surface.

The result: less visual searching and a more direct path from file to map.
