# BloomMD source code is now public

The current BloomMD source code is available in the [public GitHub repository](https://github.com/moellenbeck-digital/BloomMD). The monorepo contains the applications, shared Markdown logic, and the Obsidian plugin. You can report bugs and suggest changes in [issues](https://github.com/moellenbeck-digital/BloomMD/issues); the [contribution guide](https://github.com/moellenbeck-digital/BloomMD/blob/main/CONTRIBUTING.md) explains how to participate.

![GitHub showing the public BloomMD repository, its main branch and source folders, plus links to the license, contribution guide, and security policy](/news/bloommd-public-repository.png)

*Actual screenshot of the public repository on October 25, 2026.*

## Which license applies?

Current BloomMD source code is under the [Elastic License 2.0](https://github.com/moellenbeck-digital/BloomMD/blob/main/LICENSE). ELv2 is a source-available license with use restrictions, not an OSI-approved open-source license. The [Obsidian plugin](https://github.com/moellenbeck-digital/BloomMD/tree/main/plugins/obsidian) remains separately licensed under MIT. Previously published versions retain their respective licenses; the [license overview](/lizenz?lang=en) explains the transition.

## What happened to earlier releases?

Earlier [Desktop and CLI downloads](https://github.com/moellenbeck-digital/BloomMD/releases) remain at the same release URLs. Their binaries come from the original builds. The public source repository starts with a reviewed snapshot; earlier Git commits are not part of it. The migrated release notes explain the build origin and license status.

The [separate Obsidian repository](https://github.com/moellenbeck-digital/bloommd-obsidian) remains a release mirror for BRAT and manual installs. Development takes place in the BloomMD monorepo.

Please report unpatched security vulnerabilities [privately](https://github.com/moellenbeck-digital/BloomMD/blob/main/SECURITY.md) rather than in a public issue.

The [availability overview](/download?lang=en#availability) shows what you can download without an invitation and which features are part of the closed beta.
