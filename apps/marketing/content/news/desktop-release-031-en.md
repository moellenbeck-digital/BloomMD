# BloomMD Desktop 0.3.1 is available

The new BloomMD macOS release makes moving between the workspace overview and an individual Markdown file clear and lossless.

## What is new

- After opening a folder and a file, a visible path takes you back to the workspace overview.
- The local folder or active remote workspace stays selected.
- Focus and file context are restored after navigating back.
- `Cmd/Ctrl + ←` returns to the workspace overview; `Cmd/Ctrl + →` reopens the
  most recently opened file.

The macOS arm64 build is now available for the closed beta: [Download Desktop 0.3.1](https://github.com/moellenbeck-digital/BloomMD/releases/download/v0.3.1/stable-macos-arm64-BloomMD.dmg).
