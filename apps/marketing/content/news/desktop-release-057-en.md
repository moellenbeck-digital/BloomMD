# BloomMD Desktop 0.5.7: signed macOS installation

The macOS arm64 release of BloomMD 0.5.7 is Developer ID signed and notarized by Apple.
The release checks both the DMG installer and the app archive used for updates before publication.

Open the DMG, drag BloomMD into Applications, and launch it there. A manual Gatekeeper exception
is not part of the installation procedure. Intel Macs and Windows are not covered by this macOS release.
