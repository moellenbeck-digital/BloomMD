# BloomMD Desktop 0.5.7: signierte macOS-Installation

Der macOS-arm64-Release von BloomMD 0.5.7 ist mit Developer ID signiert und von Apple notarisiert.
Vor der Veröffentlichung werden sowohl der DMG-Installer als auch das App-Archiv für Updates geprüft.

DMG öffnen, BloomMD in den Programme-Ordner ziehen und dort starten. Eine manuelle Gatekeeper-Ausnahme
gehört nicht zum Installationsablauf. Intel-Macs und Windows sind von diesem macOS-Release nicht abgedeckt.
