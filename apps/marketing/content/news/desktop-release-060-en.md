# BloomMD Desktop 0.6.0: from folders to the right section

The folder overview now makes each object recognizable: dashed folders, blue-outlined Markdown files and compact heading previews. Type labels and icons complement the colors. Orange marks the current selection.

![Native macOS folder overview showing Projektwissen, its Team folder, the Projektplan file and the selected Ziele heading preview](/releases/desktop-0.6.0-overview.png)

**Open** on a file opens its editable map. Select a heading and **Edit section** to open that section in the editor. **Back to folder overview** saves edits and restores selection, expanded branches and the view.

**New file** on the selected folder preselects that folder in the dialog. New nodes receive focus once their title input is visible. The initial view waits for the completed layout; subsequent edits do not recenter the entire map.

The screenshots show real native macOS interactions with neutral sample files. The owner checked the macOS test build before release preparation. This desktop release does not publish a new Mobile app or Obsidian plugin.

See the [desktop guide](/docs/desktop?lang=en). The [release page](https://github.com/moellenbeck-digital/BloomMD/releases/tag/v0.6.0) contains packages and build evidence.
