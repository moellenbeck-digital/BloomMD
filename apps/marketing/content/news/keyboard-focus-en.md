# Focus stays on the right node while you work

Fast mind map editing only works when it stays clear where you are. BloomMD now keeps focus on the expected node after common editing actions.

## Less searching

The renamed node stays active. When a node is deleted or restored with undo, selection continues in a predictable place — the parent node after a deletion in particular.

This makes keyboard workflows with Return, Backspace and undo easier to follow.
