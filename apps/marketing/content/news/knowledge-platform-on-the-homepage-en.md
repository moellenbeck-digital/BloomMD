# BloomMD homepage: product, pilot and roadmap clearly separated

BloomMD lets you work with Markdown files as visual maps today. The [demo](/demo?lang=en) shows a real file and its map. The desktop beta is available from [Downloads](/download?lang=en).

The homepage now explains the direction immediately after this product proof. The [internal learnings pilot](https://github.com/moellenbeck-digital/BloomMD/issues/116) tests a first use of the backend platform. Sources and trust, offline work and connectors, access and cited search, and review and agent actions are areas for exploration. They are clearly marked as planned. The [roadmap](/en/roadmap) describes all ten topics and their current status.

There are three clear entry paths: try locally, create a web account, or help shape the direction. Use cases and three example templates continue to show how Markdown and the map work together. Orange action buttons now have improved text contrast.
