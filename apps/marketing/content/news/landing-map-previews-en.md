# Landing page mind maps now use BloomMD styling

A product preview should feel like the product. The mind map examples on the landing page now use the same visual language as BloomMD itself.

The previews are built from real Markdown structures and show the grid, nodes, edges and focus styling across the German and English marketing pages and different screen sizes.

That makes it possible to see what BloomMD does with a Markdown file before opening the demo.
