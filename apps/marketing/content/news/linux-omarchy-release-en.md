# BloomMD Desktop is now available for Omarchy and Linux

BloomMD is no longer only a macOS desktop beta. With `v0.5.0`, a separate Linux beta track starts for Omarchy 4 and other Arch-based systems.

## Native Pacman packages

The closed beta includes native packages for `x86_64` and `aarch64`. Install them with Pacman, then open files and folders directly from the Linux desktop.

The package registers Markdown files and the cross-platform `bloommd://` URI scheme. A file manager, link or another tool can therefore launch BloomMD directly with a file or folder.

The matching packages and a short installation guide are available on the [download page](/download?lang=en). Linux remains a separate beta track; the following patch releases further stabilized the Pacman bundle and secure profile storage.
