# Markdown lists and checklists are now easier to read

Lists should be recognizable as lists while you write. We have therefore refined the MDX editor: bullets, numbered lists and checkboxes now have consistent visual spacing from their text.

The change applies to the web application and the macOS app. Existing Markdown content remains unchanged; the adjustment is in the editor presentation.

This makes the next step in the focus and keyboard workflow easier to read: edit content, recognize its formatting and keep writing without searching for the active line.
