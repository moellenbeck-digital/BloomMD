# The Obsidian plugin now has one clear source

The BloomMD Obsidian plugin is developed in the monorepo together with the Markdown and structure logic. The public `bloommd-obsidian` repository remains a traceable release mirror for users and BRAT.

Shared logic now has one home, while Obsidian-specific vault, view and settings behavior stays in the plugin. Releases can be generated reproducibly from the canonical development state.
