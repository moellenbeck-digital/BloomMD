# Shared maps now show active collaborators

When several people work on a map, the shared context should stay visible. BloomMD now shows active collaborators and their current node selection in a shared workspace.

Presence information belongs to the sync session and stays separate from Markdown content. You can see where others are working without putting node text into presence data.

This gives reviews, coordination and shared navigation a clearer point of reference.
