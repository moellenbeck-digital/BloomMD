# TypeScript

Eine typisierte Obermenge von JavaScript.

## Typen

Die Grundbausteine.

### Primitive

string, number, boolean, null, undefined.

### Arrays

number[], string[], oder Array<T>.

### Objekte

Interfaces und Type Aliases.

## Funktionen

Typisierte Parameter und Rueckgabewerte.

### Generics

Wiederverwendbare Typen mit Typparametern.

### Overloads

Mehrere Signaturen fuer eine Funktion.

## Tooling

Was TypeScript besonders macht.

### Compiler

tsc — transpiliert und prueft.

### LSP

IntelliSense, Refactoring, Go-to-Definition.
