# Historical releases / Historische Releases

## Deutsch

Dieses Repository beginnt mit einem bereinigten Quell-Snapshot und enthält
die frühere private Git-Historie nicht. Historische Binärdateien werden als
unveränderte Distributionskopien mit ihrer ursprünglichen Version und
Prüfsumme bereitgestellt. Ein GitHub-Quellarchiv zu einem übernommenen
Release-Tag ist **nicht** der Quellstand, aus dem diese historische Binärdatei
gebaut wurde. Der ursprüngliche Commit bleibt im privaten Archiv für die
Wartung nachvollziehbar.

Desktop-Releases bis einschließlich `v0.5.14` behalten ihre ursprüngliche
MIT-Lizenz. Desktop `v0.5.15` wurde unter der Elastic License 2.0 (ELv2)
ausgeliefert. Die historischen CLI- und OpenClaw-Releases bis `0.4.4`
stammen ebenfalls aus einem MIT-lizenzierten Quellstand. Für weitere
Artefakte gilt der Lizenzhinweis des jeweiligen Releases. Der aktuelle
Quell-Snapshot steht unter [ELv2](../LICENSE); der
historische MIT-Text steht in [LICENSE-MIT-legacy](../LICENSE-MIT-legacy).

Das frühere interne Release `feedback-assets` mit einem Issue-Video gehört
nicht zur öffentlichen Distribution.

## English

This repository starts with a reviewed source snapshot and does not contain
the earlier private Git history. Historical binaries are distributed as
unchanged copies with their original version and checksum. A GitHub source
archive generated from an imported release tag is **not** the source revision
that produced that historical binary. Maintainers retain the original commit
in the private archive for provenance.

Desktop releases through `v0.5.14` keep their original MIT license. Desktop
`v0.5.15` was distributed under the Elastic License 2.0 (ELv2). Historical
CLI and OpenClaw releases through `0.4.4` also come from MIT-licensed source.
For other artifacts, consult the license note in the specific release. The current
source snapshot uses [ELv2](../LICENSE); the historical MIT text is in
[LICENSE-MIT-legacy](../LICENSE-MIT-legacy).

The former internal `feedback-assets` release containing an issue video is
excluded from the public distribution.
