# Content Strategy Map <!-- bloommd:id=content-root -->

A working content system for turning positioning, channels, production and metrics into a repeatable publishing engine.

## Audience <!-- bloommd:id=content-audience -->

Primary audience: Markdown users who already have useful notes but need a faster way to understand structure.

## Positioning <!-- bloommd:id=content-positioning -->

BloomMD is the visual layer for Markdown. It makes files easier to understand without moving them into a closed workspace.

## Content Pillars <!-- bloommd:id=content-pillars -->

- Local-first productivity
- Markdown workflows
- Obsidian companion use cases
- Templates for real work

## Channels <!-- bloommd:id=content-channels -->

- GitHub for builders and trust.
- Reddit for use-case discussions.
- X for short demos and launch clips.
- Obsidian community for focused beta feedback.

## Formats <!-- bloommd:id=content-formats -->

- 20-second GIFs
- Template walkthroughs
- Before/after Markdown transformations
- Privacy-focused local-first explanations

## Campaigns <!-- bloommd:id=content-campaigns -->

Launch campaign: publish six templates, one demo page and three short GIFs that all point to the same no-login demo.

## Production <!-- bloommd:id=content-production -->

Batch one template per day. Each template produces a landing page, screenshot, short clip and social post.

## Distribution <!-- bloommd:id=content-distribution -->

Repurpose every demo asset across GitHub README, X, Reddit and the landing page. Keep copy specific to each audience.

## Metrics <!-- bloommd:id=content-metrics -->

- Demo opened
- Template opened
- Own Markdown pasted
- Download clicked
- Obsidian plugin clicked
